OLGA IA — PUBLICACIÓN EN NETLIFY CON GEMINI
===========================================

ESTE PAQUETE ES PARA EL SITIO PUBLICADO EN NETLIFY.
No uses solamente el HTML ni el ZIP del proxy local anterior. Este proyecto incluye una Netlify Function que hace la llamada a Gemini desde el servidor.

QUÉ INCLUYE
- public/index.html: Olga preparada para detectar automáticamente el endpoint de Netlify.
- netlify/functions/gemini.mjs: función privada que recibe la solicitud, agrega la API key en el servidor y llama a Gemini Interactions API.
- netlify.toml: configura el directorio público y el directorio de Functions.
- Control básico de tamaño y frecuencia por IP. Para producción con mucho tráfico, añadí autenticación/captcha y rate limiting persistente.

PASO 1 — CONFIGURAR LA API KEY EN NETLIFY
1. Entrá al panel de Netlify y abrí el sitio aquamarine-ganache-cd2e00 (o el sitio que corresponda).
2. Entrá a Project configuration > Environment variables.
3. Creá una variable:
   Key: GEMINI_API_KEY
   Value: TU_CLAVE_PRIVADA_DE_GOOGLE_AI_STUDIO
4. Asegurate de que la variable tenga alcance Functions (o All scopes).
5. Guardá los cambios. Nunca pegues la clave en el HTML, JavaScript, chat ni repositorio.

PASO 2 — PUBLICAR EL PROYECTO COMPLETO
Las Netlify Functions no se publican subiendo solamente el index.html ni con un deploy estático simple.

Opción recomendada (Netlify CLI):
1. Instalá Node.js 20 o superior.
2. Abrí una terminal dentro de esta carpeta (la que contiene netlify.toml).
3. Ejecutá:
   npm install -g netlify-cli
   netlify login
   netlify link
4. Elegí el sitio existente de Olga.
5. Ejecutá:
   netlify deploy --prod
6. Confirmá que la publicación terminó correctamente.

También podés conectar esta carpeta a un repositorio Git y configurar Netlify para desplegar desde allí. El directorio de funciones es netlify/functions y el directorio publicado es public.

PASO 3 — COMPROBAR LA FUNCIÓN
Abrí esta dirección en el navegador:
https://TU-SITIO.netlify.app/.netlify/functions/gemini

Debe responder algo parecido a:
{"ok":true,"service":"olga-gemini-netlify-function"}

Después abrí el sitio de Olga, entrá en Personalizar > Conexión con Gemini IA y tocá “Probar conexión Gemini”. El campo del proxy debería completarse automáticamente con:
https://TU-SITIO.netlify.app/.netlify/functions/gemini

IMPORTANTE
- El navegador ya no debe llamar directamente a https://generativelanguage.googleapis.com.
- La función de Netlify llama a Google desde el servidor y no entrega la API key al navegador.
- El límite por IP incluido es básico y depende de la instancia serverless; no reemplaza protección antiabuso persistente. Antes de campañas públicas conviene sumar CAPTCHA/autenticación y rate limiting distribuido.
- Si actualizás GEMINI_API_KEY, volvé a desplegar el sitio para asegurarte de que la función use la nueva configuración.
- Si Google devuelve un error HTTP, la función lo transmite a Olga para mostrar el detalle de la API.
